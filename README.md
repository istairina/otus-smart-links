# Курсовой проект "Умные ссылки"

## Описание проекта
Пользователь переходит по ссылке и в зависимости от параметров осуществляется редирект на определенные адреса.
Реализованы следующие критерии:
1. Используемый браузер
2. Время получения запроса
3. Предпочтитаемый язык
Возможно добавление новых условий и правил.

## Микросервисная архитектура

1. Сервис по работе с базой данных правил (в курсовом проекте использована in-memory database)
2. Сервис по работе с правилами - поиск подходящего правила и возврат actions этого правила
3. Сервис редиректа (получение запроса от клиента и ответ ссылкой для перехода)

Использован монорепозиторий и общие компоненты вынесены в отдельный сервис shared.


## Запуск в режиме разработки

Требуется настроить переменные окружения для каждого сервиса (использовать .env.example как шаблон)

запуск отдельных сервисов из соответствующий папок
```bash
npm run dev
```
или аналогичная команда из корня репозитория для запуска всех сервисов


## Запуск в Docker

Для запуска в докере требуется настроить переменные окружения для всего проекта (располагаются в корне репозитория, шаблон .env.example)

```bash
docker-compose up
```


## Тестирование

Проект использует Jest для тестирования с требованием покрытия кода не менее 90%.

### Запуск тестов

Для запуска тестов:
```bash
npm test
```


Для запуска тестов проекта с проверкой покрытия:
```bash
npm run test:coverage
```


### Покрытие кода

Все сервисы настроены на минимальное покрытие 90%.
Отчеты о покрытии генерируются в директории `coverage/` каждого сервиса.
